# Technical level

**Level:** never coded | beginner | intermediate | professional

## What this means for agents

Use with [`/what`](../skills/what/SKILL.md) and every response. When in doubt, explain one level simpler.

| Level | Vocabulary | OK to assume | Always explain |
|-------|------------|--------------|----------------|
| **never coded** | Plain English only; no acronyms without gloss | Nothing about IDE, git, terminals, repos | What Cursor is, what a "file" or "folder" is, where actions happen |
| **beginner** | Define jargon on first use | Basic computer literacy | git commit, branch, API, env vars before using them |
| **intermediate** | Standard dev terms | IDE, git, npm/pip, REST, tests | Project-specific architecture, internal conventions |
| **professional** | Terse; skip tutorials | Full stack toolchain | Nothing unless ambiguous |
