# App building blocks

Short fundamentals for people who have **never coded** or are **beginners** — read before or during your first Adam build.

Each module is ~2–5 minutes. Same structure everywhere:

- **Simple** — analogy
- **Practical** — one thing you’ll see in Cursor
- **Technical** — where to go deeper (we route out; we don’t replace official docs)

**Opt-in teach mode:** If you picked *Teach me* in calibration, Adam can show a linked module (or a one-line **Teach hook** from your current slice) before a major step. Say **Just build it** anytime to skip hooks; use **`/what?`** when a term is confusing.
