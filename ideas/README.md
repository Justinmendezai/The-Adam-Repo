# Ideas inbox

Raw brainstorm drops land here **before** they become plans, council inputs, or memory.

Pattern:

1. Drop `idea-<slug>.md` (or any name) in this folder.
2. Adam (or you) triages: defer, research, council pass, or promote to `packet/` / `plan/`.
3. After promotion, link back from the idea file — don't delete history.

This folder is intentionally messy. Deterministic triage beats premature structure.

See also: `adam/memory/research/` for post-research artifacts.
