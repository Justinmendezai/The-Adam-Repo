# Context templates

Copy into your product repo as `adam/context/*.md` during **`calibrate`**, or let **`setup-adam`** seed them.

Files:

- `user-profile.template.md`
- `technical-level.template.md`
- `preferences.template.md`
- `founder.template.md`
- `project.template.md`

Every agent reads these before responding in a calibrated project.
