# Memory

Durable project knowledge outside throwaway `scratch/`. Agents update after meaningful decisions.

| Folder | Use |
|--------|-----|
| `architecture/` | System boundaries, diagrams, invariants |
| `bugs/` | Known issues, repro, workarounds |
| `decisions/` | Decision log (mirrors `plan/adr/` for quick agent reads) |
| `features/` | Feature intent, acceptance, status |
| `gtm/` | Go-to-market notes |
| `handoffs/` | Archived session handoffs |
| `research/` | Synthesized research (raw dumps also in `scratch/research/`) |

Keep files small and dated. Prefer links to `plan/` and `slices/` over duplication.
